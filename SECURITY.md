# Security policy

## Supported versions

Only the latest release of Perch for Home Assistant gets security fixes.

## Reporting a problem

Please report security problems privately through
[Report a vulnerability](https://github.com/RoBroLabs/perch-homeassistant/security/advisories/new)
on the Security tab. Do not open a public issue.

Include what you found, how to reproduce it, and the versions of Perch for Home Assistant
and Home Assistant you used. You will get a reply within a few days, and a fix or a plan
before any details are made public.

How Perch keeps pairing and the TV connection local, and the reverse-proxy caveat, are
described in the [security notes](docs/guide.md#security-notes).
