# Contributing

Thanks for helping with Perch for Home Assistant.

- **Bugs and ideas:** open an issue using the bug report or feature request form.
- **Security problems:** report them privately, see [SECURITY.md](SECURITY.md).
- **Code:** open a pull request against `main`. Keep it to one change, add or update tests,
  and make sure `pytest` passes. Setup and test commands are in
  [docs/development.md](docs/development.md).
- **Protocol:** do not edit `protocol/`. It is a pinned copy of the Perch app's protocol.

Style: British English, plain and short. Never commit a token, password or address from
your own home.
